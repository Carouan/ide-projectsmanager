# IDE Projects Manager v1.0.0

Première version publique stable d'un IDE personnel de gestion de projets,
local-first et installable comme PWA.

## Fonctionnalités principales

- Portefeuille responsive : recherche, filtres, tri, progression et attention
  humaine réellement nécessaire.
- Projets structurés en étapes, backlog, journal, décisions, pièces jointes et
  chantiers parallèles.
- Progression explicable à partir des objectifs vérifiables d'une roadmap,
  d'une estimation déclarée ou de l'étape actuelle.
- Lecture GitHub publique ; lecture privée facultative, limitée à la session.
- Préparation guidée de projets gouvernés sans publication automatique.
- Sauvegardes JSON globales, dossier choisi explicitement, instantanés par
  appareil et revue des divergences.
- Thèmes clair/sombre/système, taille de texte, contraste, réduction des
  animations et navigation clavier.
- Documentation française/anglaise et wiki utilisateur synchronisé.

## Fichiers téléchargeables

- `ide-projectsmanager-v1.0.0-web.zip` : application web statique compilée.
- `ide-projectsmanager-v1.0.0-web.zip.sha256` : empreinte SHA-256 associée.

L'archive contient `INSTALLATION.md` et doit être servie par un serveur web
sous le chemin `/ide-projectsmanager/`. Elle ne constitue pas un installateur
Windows ou Android natif.

## Validation et limites

Le choix d'un dossier et l'écriture de l'instantané ont été effectivement
confirmés sur Windows et Android. Deux dossiers locaux ne se synchronisent pas
entre eux sans un transport commun.

Les essais physiques sur un autre navigateur, la restauration entre appareils,
le partage natif, les relais facultatifs, WebRTC/QR, l'import UFI/SUMP et la
personnalisation avancée restent des chantiers post-release clairement séparés.
