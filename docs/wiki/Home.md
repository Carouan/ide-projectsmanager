# IDE Projects Manager — documentation utilisateur

IDE Projects Manager est un **IDE personnel de gestion de projets** : il aide à
capturer les idées, structurer les étapes, organiser les chantiers, suivre les
décisions et sauvegarder ses projets sans dépendre d'un compte distant.

Les données actives restent locales au navigateur. Un dépôt GitHub lié apporte,
lorsqu'il existe, une lecture complémentaire de sa roadmap et de ses validations.

## Commencer

1. [Démarrer et gérer un projet](Guide-utilisateur).
2. Structurer les étapes `v.0.0 → v.1.0` et les chantiers parallèles.
3. Comprendre pourquoi un pourcentage provient de la roadmap, d'une valeur
   déclarée ou de l'étape courante.
4. [Sauvegarder ses projets et comparer les appareils](Sauvegardes-et-appareils).
5. Adapter le thème, la taille du texte, le contraste et les animations dans
   **Paramètres**.

## Ce qui fonctionne aujourd'hui

- Tableau de bord responsive avec recherche, filtres, tri et vue grille/liste.
- Projets, étapes, backlog, journal, décisions, pièces jointes et chantiers.
- Progression mesurable, roadmap GitHub et attention humaine nécessaire.
- Sauvegardes JSON, dossiers choisis explicitement et instantanés par appareil.
- Création guidée de projets gouvernés et lecture GitHub privée facultative.
- Thèmes système/sombre/clair, langue française/anglaise et réglages
  d'accessibilité.
- Application web installable en PWA.

## Limites expliquées honnêtement

Un dossier sur Windows et un dossier sur Android ne deviennent pas partagés
par magie : un transfert ou un synchroniseur doit effectivement déplacer les
instantanés. Aucun projet n'est remplacé automatiquement ; toute restauration
demande une décision explicite.

Le choix du dossier et l'écriture ont été confirmés sur Windows et Android. Les
essais sur un autre navigateur, les transports réels et la restauration physique
entre deux appareils restent reportés.
